# Hnefatafl (Viking Chess) Pygame
**Asymmetric strategy game from the 4th-12th century**

[![Python](https://img.shields.io/badge/Python-3.12%2B-3776ab?logo=python&logoColor=white)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Built%20with-Pygame-brightgreen)](https://www.pygame.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey)](#install--play)

Hnefatafl ("Viking Chess") is one of the oldest known strategy games, played across Northern Europe long before chess arrived. One player commands a king and his defenders trying to escape to the board's edge, the other commands an army of attackers trying to trap him first.

## How to Play

The game is made for two players sharing the same computer, taking alternating turns.

See **[rules](docs/rules.md)** for gameplay details.

## Install & Play

- [Download latest Windows release](https://github.com/joaquinkiko/hnefatafl-pygame/releases/latest/download/Tafl-windows.zip)

- [Download latest Linux release](https://github.com/joaquinkiko/hnefatafl-pygame/releases/latest/download/Tafl-linux.tgz)

## Run from Source

**Requirements:**
- Python 3.12+

```bash
git clone https://github.com/joaquinkiko/hnefatafl-pygame.git
cd hnefatafl-pygame
pip install -r requirements
python main.py
```
